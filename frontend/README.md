# Acme Portal Client

The Next.js frontend for Acme Portal.

## Running

```bash
npm ci
npm run dev
```

The client serves on `http://localhost:3000` and expects the API at
`http://localhost:8000`.

## Commands

| Command         | Purpose                       |
| --------------- | ----------------------------- |
| `npm run dev`   | Development server            |
| `npm run build` | Production build              |
| `npm run start` | Serve a production build      |
| `npm run lint`  | ESLint                        |
